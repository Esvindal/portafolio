Cámara → Telegram

Python · Digest auth · multipart streams

Escucha el flujo de eventos de una cámara o NVR (Dahua / Hikvision), toma la foto del momento y la manda a un chat de Telegram en segundos. Registra cada evento en SQLite y exporta a CSV.

Qué es real

  • El pipeline completo: evento → foto → sendPhoto → registro.
  • Los parsers de los protocolos HTTP de Dahua e Hikvision, verificados contra documentación pública.
  • Un simulador que genera eventos y fotos para probar todo sin cámara.
  • 37 pruebas automáticas que corren sin red.

Probado con el simulador; la conexión a la cámara real está a verificar en dispositivo (hay un guion de grabación en el repo).

Seguimiento de precios

Python · GitHub Actions · GitHub Pages

Un scraper que corre solo cada 6 horas (GitHub Actions), guarda el historial de precios y hace commit solo si algo cambió. Una página muestra la evolución, una tabla comparativa y alertas de bajada.

Qué es real

  • Los datos: 60 productos descargados de verdad de books.toscrape.com, un sitio creado para practicar scraping.
  • El historial idempotente y las reglas de alerta, con 14 pruebas.
  • El workflow programado con commit condicional.

La fuente es de práctica y sus precios son estables; el gráfico será plano hasta que el sitio cambie precios. El workflow se activa al publicar el repo en GitHub.

Repositorio Sitio del demo

Analizador de accesos

HTML/CSS/JS · 100% en el navegador

Subís un CSV de eventos de acceso y ves horas pico, rechazos repetidos y anomalías, con un informe descargable. Nada se sube a ningún servidor: todo se procesa en tu propia máquina.

Qué es real

  • El análisis completo corre en JavaScript del lado del cliente.
  • 5 pruebas de punta a punta con Playwright sobre Chrome real.
  • Un generador de datos de ejemplo (marcados como generados) para probarla sin CSV propio.

Funciona hoy mismo: abrí la página y probala con los datos de ejemplo.
